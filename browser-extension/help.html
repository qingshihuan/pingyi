SCREEN INSIGHT FOR YOUR BROWSER

网页翻译，接回你的截屏释义。

模型和 API 在桌面端管理。插件只负责网页交互，不接收服务密钥。

首次连接

  1. 运行包含浏览器连接功能的新版 截屏释义 桌面端。已发布的 v0.5.2 尚不包含此功能，需要从本次源码构建。
  2. 发布并注册连接组件，命令见插件目录的 README.md；Windows 与 Ubuntu 都支持按当前用户注册。
  3. 在扩展管理页选择“加载已解压的扩展程序”，选择 browser-extension 文件夹。
  4. 打开插件面板，选择与桌面端相同的标准版或完全版，再点击“重新连接”。

四种翻译方式

  • 网页翻译：点击主按钮或按 Alt+A。双语模式在原段落下附加译文；仅译文模式可随时恢复。一次最多 200 段，每段最多 12,000 字。
  • 鼠标悬停：打开开关，按住 Alt 并在段落上停留约 650 毫秒。
  • 划词翻译：选中文字后点击“截屏释义”浮标，也可使用右键菜单。
  • 圈选翻译：点击圈选或按 Alt+S，拖动框选当前网页可见区域。Esc 取消。仅裁剪区域交给 截屏释义 OCR。

语言、服务与隐私

默认自动检测原文语言、翻译为简体中文。浏览器本机检测与 截屏释义 路由共同处理自动语言；短句或混合语言可能误判，可手动选择。基础 Argos 只支持中英，其他语言需要对应模型或 API。

远程翻译每个页面、每组服务配置首次使用时询问；远程 OCR 每张截图单独询问。插件只保存语言、显示模式、开关和版本偏好，不保存正文、截图、译文或凭据，不包含统计或远程资源。网页内嵌译文可以被网页自身读取。

当前边界

Chrome / Edge Manifest V3，普通 HTTP / HTTPS 网页。浏览器内部页面、扩展商店、内置 PDF 查看器、跨域 iframe、封闭 Shadow DOM 不支持正文翻译；iframe 和画布中的内容可使用可见区域圈选。动态加载的正文需要再次翻译。未提供文档批处理、登录或订阅功能。

操作取消后不会继续排队新段落；已交给模型的当前请求仍可能完成。切换显示模式会恢复已有网页译文，请再次点击翻译。快捷键冲突可在浏览器扩展快捷键页调整。

连接不上

确认已启动新版桌面端、选择正确版本，并已注册连接组件。移动连接组件后需要重新注册。远程服务错误和离线模型缺失请到 截屏释义 设置中检查。插件不会自动安装、下载或启动模型以外的软件。
