# 图片分析与本机模型就绪检查

## 使用

主页的“描述图片”和“反推提示词”直接框选屏幕图像，不先运行 OCR，也不因没有文字而失败。结果窗口可以对内存中同一张截图重新描述、反推，或返回文字翻译；复制图片分析仅复制生成内容，不附带空原文/译文标题。

这两项功能使用“自定义接口”中已保存的兼容视觉模型与密钥。完全版已安装并应用的本机多模态模型可以按需启动，即使当前 OCR/翻译方案为离线基础。标准版也可以连接自己运行的兼容视觉服务。模型必须支持 `image_url`；文字模型、PaddleOCR、Argos 不能替代图片语义理解。输出语言跟随发起任务时的界面语言。反推只是相似画面的参考描述，不恢复原始提示词、种子、设备或作者，不保证复现效果。

## 数据范围与限制

本机回环服务直接接收图片；远程只允许 HTTPS，每一次分析/重试均先确认完整所选截图的接收地址与模型，再发送。拒绝或取消确认不发送图片。授权绑定当前端点/模型快照，设置发生变化则终止，不能把截图改送其他服务；HTTP 客户端禁用自动重定向。禁止地址内嵌用户名/密码。沿用系统密钥存储，不新增图片、结果或提示词持久历史。

输入 PNG 限制 32 MiB 和 3200 万解码像素，长边缩小至不超过 1600 像素；输出最多读取 256 KiB，输出 token 上限 1536。返回空白、畸形数据、不支持图片、超长内容或超时都会显示错误，不冒充 OCR/翻译成功，也不静默上传备用服务。模型可能遗漏/看错，应核对结果。网络错误不回显服务器响应正文或密钥。此功能的网络与内容留存范围不同于仅上传 OCR 文字的翻译。

## 就绪检查修复

旧启动逻辑的单次 2 秒 HTTP 超时可能逃出探测循环，被错误显示成整体 75 秒加载超时。现在单次超时/连接失败/503/无效 JSON 都继续在同一个总期限内检查；`/health` 明确返回 `status: ok` 且 `/v1/models` 匹配预期别名才算就绪。Vulkan 冷启动最多 3 分钟，CPU 最多 5 分钟；AppServices 的共享加载事务和截图等待预算为 10 分钟，覆盖自动回退和校验。已加载且仍活着的自有模型不会仅因为 12 秒健康检查失败就被杀掉，提示稍后重试。

只在自动后端下尝试 Vulkan → CPU，显式取消传入的启动令牌不触发 CPU 回退；停止旧进程后等待退出，避免并存争用端口。设置或截图发起的共享加载可能被后续截图复用：“取消等待”取消当前请求，并不保证终止其他使用者共享的模型加载。应用退出仍取消服务生命周期并释放进程。

原生 stdout/stderr 按固定缓冲区排空，仅保留预定义的内存、端口或 Vulkan 错误类别，不缓存任意服务器长行或提示词。错误提示不是对显卡驱动/模型硬件兼容性的保证。

## 验证

自动回归覆盖短探测超时恢复、503 和错误别名、总期限、取消、进程早退；无文字合成图片请求、PNG 缩放、提示词任务、响应错误/上限、不安全地址拒绝与取消；真实按钮路由、确认/拒绝、结果区扩展、复制与中英切换、最小窗口布局。C# 测试通过双平台 CI 执行，Python 引擎与脚本测试同时保留。渲染预览使用明确合成数据，不代表真实视觉模型质量或用户显卡已验证。发布仍需通过原有全套测试、质量基线与许可证审计。
