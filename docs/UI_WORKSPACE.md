# 截图工作台与分类设置

本次重做使用现有 Avalonia 桌面窗口，不引入网页壳或新的运行时依赖。主界面优先展示截图入口、真实快捷键、模型状态和隐私范围；处理方案保留原有预设切换入口。

## 设置分类

| 分类 | 内容 |
| --- | --- |
| 识别与翻译 | OCR、翻译提供商、目标语言、检查状态；保留立即生效行为 |
| 本地模型 | 基础 OCR/翻译模型、完全版本机大模型、清理下载模型 |
| 云端服务 | 百度和 Google 凭据，沿用安全存储与保存/验证流程 |
| 自定义接口 | 服务预设、地址、模型名、密钥，分别测试文字与图片 |
| 外观与启动 | 界面样式、界面语言、快捷键、托盘启动、更新与完整界面入口 |

各页单独滚动，左侧分类、底部状态和“保存并应用”保持可访问。静态 TabItem 内容只构建一次，切换分类不会重建输入框或丢失未保存输入。引擎与目标语言沿用立即生效；其他设置按原有保存、应用预设或验证按钮的行为执行，不伪装为全部自动保存。

## 快捷操作

- `Ctrl+Alt+D`：默认全局截图键，仍可按原方式修改。
- `Ctrl+,`：在工作台打开设置。
- `F5`：在工作台刷新模型与服务可用性。
- `Ctrl+S`：在设置/完整界面调用现有保存与验证流程。

## 兼容与安全边界

保留原有全部具名字段、事件处理程序和六种密钥路由。截图、OCR、翻译、模型下载、设置存储、凭据存储和 provider 选择的实现均不在此次改造范围内。隐私摘要仍由当前配置生成，不根据视觉主题推断联网状态。没有新增历史记录、遥测、模型文件或用户密钥。

浅色与深色共用 App 主题资源；新文案提供简体中文与 English。原“经典完整界面”入口仍提供同窗截图与全部配置，但也使用新的分类布局，不再保留旧长页的原样外观。

## 验证

```sh
python -m unittest discover -s scripts -p 'test_ui_workspace.py' -v
dotnet test PingYi.slnx -c Release
python -m unittest discover -s engine_host -p 'test_*.py'
```

结构测试检查具名控件、事件、密钥输入、分类和固定操作栏。`PingYi.App.Tests` 使用 Avalonia Headless + Skia 构建真实 XAML 控件，覆盖最小/默认窗口、中英文、浅深主题、分类输入保留、错误反馈和保存入口。测试不创建 AppServices，不截取桌面、不访问模型或凭据。设置 `PINGYI_UI_ARTIFACTS` 可导出人工布局审阅所需 PNG；CI 保存七天的测试截图。

这些测试不替代 Windows/Ubuntu X11 上的真实截图、全局热键、系统安全存储和多显示器 DPI 验收。没有在本次改造中发布安装包，也未修改 Release 版本。

## 精致桌面视觉迭代

主界面、五类设置和结果卡统一使用 `Styles/ApplePalette.axaml` 的语义色。浅色采用银白背景与白色内容表面；深色采用石墨灰，不依靠低对比度灰字营造层次。蓝色作为主操作与交互强调色，成功和错误仍有文字提示，不只靠颜色区分。

- 主界面：原创“文/A”轻量符号、两行阅读标题、明确的截图主操作和快捷键；保留模型、隐私、处理方案、错误修复和底部实时状态。
- 设置：低对比背景侧栏、原创线形图标、原生 TabControl 分类与键盘语义；页内滚动和固定保存栏保持不变。
- 结果卡：原文/译文双阅读区，保留只读选择、独立复制、固定、重试、复制全部和修复入口；底部操作在小窗口中可换行。
- 字体：优先系统无衬线字体，并列出中文回退族；不会嵌入或下载新的字体文件。实际字形仍取决于主机已安装字体。

没有使用 Apple 的图标、字体文件或窗口控制素材，不添加假红黄绿按钮；保留 Windows/Ubuntu 的窗口装饰与操作习惯。本轮不新增 macOS 支持。静态渐变、轻阴影与矢量路径不引入新的动画循环、轮询器、实时模糊或网页运行时；此前按需启动与空闲回收逻辑未修改。

`ApplePolishTests` 覆盖中英文、浅深主题、原生侧栏键盘导航以及最小结果窗错误状态。`refined-*` 截图使用显式标注的合成数据，底部写明“布局预览 · 使用演示数据，未连接真实服务”；它们是实际 XAML 控件的 Headless/Skia 渲染，并非真实模型或云服务运行结果。未注入服务的原有结构/布局测试仍保留。

UI 测试只验证其列出的交互与布局条件，不代表完成真实系统截图、模型质量、全局热键、系统密钥存储或多显示器 DPI 端到端验收。没有为了展示效果写入用户设置或凭据，也没有用本轮视觉变化推算启动/内存性能收益。
