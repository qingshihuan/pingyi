# Video provenance and factual references

Product baseline: Screen Insight v0.7.0, commit `b78531e8d174e48c9250947f924cfb9aadc543c2`. Rendering source commit and hashes are recorded in `render-manifest.json` after export.

## Product claims

- `src/PingYi.App/FirstRunSetupWindow.cs` and `AppServices.InitialSetup.cs`: explicit download choice, existing-service / Lightweight alternatives, model/backend controls, cancellation and fixed request validation.
- `src/PingYi.Core/ProcessingModes.cs`: local Basic versus PaddleOCR/Argos Lightweight; remote endpoints are not labelled local Basic.
- `src/PingYi.App/CaptureCoordinator.Automatic.cs` and `src/PingYi.Core/AutomaticCapture.cs`: local content heuristics, manual choice for ambiguity, no cloud model used merely to guess intent.
- `src/PingYi.App/ResultWindow.Automatic.cs`: same-image manual task controls; prompt reconstruction is manual.
- `src/PingYi.Infrastructure/ZxingQrCodeDecoder.cs` and `docs/DESKTOP_QR.md`: local QR decoding and explicit opening of web links, not model inference.
- `docs/AUTOMATIC_CAPTURE.md`: privacy, migration and model-test limitations.
- `packaging/windows/PingYi.iss` at v0.5.2 and v0.7.0: same Complete AppId and default directory, different legacy Standard AppId.
- `docs/WINDOWS_UPGRADE.md`: current installer behavior, supported upgrade path, pending restart and portable package boundaries.

## UI imagery

Generated by `tests/PingYi.App.Tests/VideoPreviewTests.cs` from the actual application controls. The first-run UI has an available runtime flag but no real download callback is invoked. Main-window health/provider labels are authored preview values and marked as a synthetic demonstration. QR payload is the public project URL. No user screenshots, local account names, private files, API keys or real model results are included.

The project-approved icon is reused from `src/PingYi.App/Assets/screen-insight-icon-512.png`. The mountain artwork, screen-capture motifs, cursor and motion layouts are project-authored. Illustrative English/Chinese text and prompts are authored examples, not inference benchmarks. Stage animations have no wall-clock claims.

## Audio and typography

Original ambient instrumental synthesized by `media/remotion/tools/assets.py`, without borrowed recordings, protected songs, voice cloning or a TTS service. No spoken narration. Chinese captions are burned into the videos, and matching SRT files are included.

Rendering uses fonts installed on the runner (Noto Sans CJK SC). Font binaries are not included in the repository or downloadable source. Typeface appearance may vary when rendered on a machine without the same installed family.

## Development tools

Remotion 4.0.506, React and TypeScript are isolated development dependencies under `media/remotion/`, with an npm lockfile. FFmpeg encodes and validates outputs. They are not added to the desktop application's runtime. Remotion retains its own license: https://www.remotion.dev/license . Rendering documentation: https://www.remotion.dev/docs/cli/render .
