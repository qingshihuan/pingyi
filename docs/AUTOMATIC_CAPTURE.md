# 自动任务与首次配置

本页描述 schema 16 主线。轻量模式、传统 OCR 探测和逐任务模型组合已删除。

自动入口先用本地二维码解码器检测当前截图。成功则显示二维码内容，不调用模型；否则使用当前多模态模型进行识字与翻译。该流程不再以传统 OCR 判断图片语义，也不自动转为图片描述。结果窗口保留翻译、描述、二维码与提示词反推的手动入口，同一截图可切换任务；前一个任务会取消，过时结果不能覆盖新任务。

首次引导可明确选择下载并设置本机模型，或进入云端/已有本机服务配置。没有点击下载就不会安装模型。托管设置需要安装后端、校验文件、启动，并通过文字与随机图片能力验证后才保存。失败或取消不宣称成功；不会回退到已移除的轻量模式。

云端识字/翻译前明确显示目标并征求本次授权。二维码解码不联网、不主动打开链接。未配置模型时仍可解码二维码；其他任务提示到设置选择已验证当前模型。
