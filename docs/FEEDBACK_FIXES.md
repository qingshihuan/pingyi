# v0.4.0 用户反馈：五项代码修复

本轮基于主线 `7ee4ed8`。没有改变 OCR 模型、图像尺寸、识别阈值、翻译实现或生产依赖，也没有撤回按需加载和闲置进程释放。

## 单一界面

只创建一个工作台主窗口；`--settings` 打开同一套设置，不再创建另一种主界面。删除主界面样式下拉框、经典入口和对应处理程序。旧 JSON 中的 `interfaceStyle` 不再参与路由；下次保存不会再写入。迁移仅规范化旧字段，其余配置沿用。

## 多屏截图前的窗口隔离

原实现只隐藏调用窗口和一个非固定结果卡，并固定等待 140ms，无法覆盖独立设置、帮助、固定结果和 Windows 转场的中间帧。

`CaptureVisibilityScope` 在真正抓取桌面前快照本应用所有可见窗口，关闭 ComboBox/Flyout/ContextMenu，先隐藏子窗口再隐藏所有者；Windows 原生 HWND 临时使用 `DWMWA_TRANSITIONS_FORCEDISABLED`，处理完 UI 隐藏通知后等待 `DwmFlush` 和短暂合成宽限。只有完成该准备阶段才抓图并创建各显示器的框选层。框选关闭之后才恢复窗口，不通过 Opacity 透明化窗口。取消、失败和新截图接管走 finally 清理；应用退出时不把隐藏窗口重新显示。原来隐藏或已关闭的窗口不被唤醒。

`DwmFlush` 只同步调用应用排队的更新，不代表对整个桌面会话的所有显示器做硬件同步。Windows 实机仍需覆盖不同刷新率、DPI 和显示器排列；自动测试不能作为物理多屏验收。

## 即时语言切换

选择语言仅持久化 `UiLanguage`，成功后更新界面；保存失败回退选择并显示错误，不假装已生效。标题、分类、按钮、说明、弹窗与可访问名称使用同一个中英资源表，`DynamicResource` 替代一次性的 `x:Static` 文案。现有窗口原位更新；选择框重建显示项但保留对象选择，不重载设置、不写入其他未保存的表单值。

UI 翻译不触碰 `TextBox.Text`：用户原文、译文、模型名、服务地址与密钥不能被当成界面文案改写。托盘菜单同步重建。Follow system 使用系统安装界面语言：中文系统用简体中文，其余用英语。

## 可解释的方案选择

独立选择窗口以四层信息展示：名称、引擎链路、适用目的、前置条件。垂直滚动与自动换行替代长菜单，只有点“应用方案”才改变提供商；关闭或取消保持原配置。“自定义组合”直接打开设置，不覆盖接口。加入 Google 方案；远程兼容接口不会错误标为本机模型。切回离线基础时，不支持的目标语言回到中英自动互译。

没有承诺任何模型对表格/公式的识别能力，也不对未经对比的速度和精度作保证。

## 帮助与关于

主界面保留截图、处理链路、用途和状态，删除隐私卡。主界面和设置均可打开帮助窗口，读取真实构建版本和当前快捷键，按已保存的 OCR/翻译组合解释图片/文字去向。自定义远端只展示主机名，不展示 URL 用户信息、路径、查询或密钥。项目链接只指向本仓库；不增加虚构官网、快捷键或自动联网检查。

## 回归与实机验收

新增 `ProcessingModesTests`、`RemediationTests` 和结构检查。覆盖旧配置迁移、六种方案、即时切换与回切、语言保存失败、草稿/原文/密钥不变、窗口隐藏/恢复/取消/退出、窄窗口方案说明和隐私迁移。原有截图几何（含负坐标及缩放）、核心/引擎/界面测试继续执行。

Windows 实机检查：两个及以上显示器分别测试 100%/150%/200% 缩放和不同刷新率；主界面、设置与固定结果放在不同屏幕；分别从按钮、全局快捷键和设置可见状态发起截图，确认遮罩底图没有本应用窗口或弹出菜单。测试 Esc、跨屏拖动、快速再次截图和退出后不复活窗口。

UI PNG 是实际 Avalonia Headless/Skia 控件渲染，测试状态为合成演示数据；不是用户桌面或真实模型业务结果。本分支没有发布安装包。
