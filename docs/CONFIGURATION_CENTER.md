# 当前模型与设置

本页描述 schema 16 的开发主线；旧版配置中心的逐任务绑定已移除。

设置只有五个页面：当前模型、云端 API 管理、本地模型管理、快捷键、通用设置。

## 添加并选择模型

云端 API 管理用于 HTTPS 服务；本地模型管理用于本机回环服务（Ollama、LM Studio、llama.cpp 或其他兼容后端）。先添加服务，填写地址、协议和可选 API Key，再获取列表或手动填写模型 ID。获取列表不会证明模型支持图片。

分别测试文字和图片能力。测试采用合成内容，远程可能计费；图片测试答案只在随机图片中。两项都成功后，到当前模型页刷新并选择，最后保存并应用。纯文本、未测试或测试失败的模型不能设为当前模型。更换目标地址、协议或密钥后需要重新验证。

截图识字、翻译、图片描述和提示词反推共用一个选择。二维码仍本地解码，不使用模型；请求失败不会切换到其他服务。

## 本地部署与后端

本地模型页还管理应用托管的模型下载、视觉组件、推理后端、显卡和运行状态。模型与后端分别下载。托管设置会在启动和两项能力测试成功后保存当前模型；取消或失败保留原配置。外部服务的下载和启停由对应应用处理。

打开或保存设置不会预加载模型，状态页不会自动联通云端账号。详见 [运行后端管理](RUNTIME_SWITCHING.md)。

## 密钥和草稿

各服务使用独立密钥引用，包含服务标识和目标地址摘要。留空保留已保存的密钥，勾选删除才清除该服务的密钥。修改服务地址清空未保存的旧地址密钥，并要求新目标重新填写。密钥编辑值以密码形式显示；切换界面语言保留未保存输入。关闭窗口取消请求并清空未保存密钥。

文字与图片测试只验证当前草稿，不会保存配置。删除当前模型所在服务前，需先保存另一个当前模型或清空选择。配置写入失败会恢复原密钥，不改其他服务账号。
