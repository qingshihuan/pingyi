# 当前模型与设置

本页描述 schema 16 的开发主线；旧版配置中心的逐任务绑定已移除。

设置只有五个页面：当前模型、API 模型管理、本地模型管理、快捷键、通用设置。

## 添加并选择模型

API 模型管理统一连接云端 HTTPS 服务和已有的本地 API（Ollama、LM Studio、llama.cpp 或其他兼容后端），两类服务共用列表和地址预设。本地地址预设统一带“（本地）”后缀，英文界面为“(Local)”。先添加服务，填写地址、协议和可选 API Key，再获取列表或手动填写模型 ID。获取列表不会证明模型支持图片。

分别测试文字和图片能力。测试采用合成内容，远程可能计费；图片测试答案只在随机图片中。两项都成功后，到当前模型页刷新并选择，最后保存并应用。纯文本、未测试或测试失败的模型不能设为当前模型。更换目标地址、协议或密钥后需要重新验证。

截图识字、翻译、图片描述和提示词反推共用一个选择。二维码仍本地解码，不使用模型；请求失败不会切换到其他服务。

## 本地部署与后端

本地模型页作为软件基础功能，独立管理应用托管的模型下载、视觉组件、推理后端、显卡和运行状态，不包含 API 服务表单。模型与后端分别下载。托管设置会在启动和两项能力测试成功后保存当前模型；取消或失败保留原配置。外部服务的下载和启停由对应应用处理。

打开或保存设置不会预加载模型，状态页不会自动联通云端账号。详见 [运行后端管理](RUNTIME_SWITCHING.md)。

## 运行状态自动更新

首页和本地模型页的运行状态详情在窗口可见时每两秒检查本地信息，配置保存后立即请求刷新。窗口隐藏、最小化或模型配置进行中会暂缓检查，关闭窗口会取消未完成检查；模型进程启动或停止不会继续使用旧的运行状态缓存。刷新重叠时保留后续请求，不因忙碌而丢失新的配置状态。

绿色表示本地可用或按需加载；蓝色“已验证”表示已有模型的图片、文字能力测试结果已保存，不代表本次已检查服务连通性、余额或额度。尚未测试的 API 继续显示“待验证”。测试草稿需要保存并应用后才会更新首页。状态刷新不联网调用 API、不下载或启动模型、不修改配置或密钥；未变化的检查结果不会覆盖操作提示或重建详情按钮。

## 远程发送提示

截图识字/翻译与图片分析弹窗均提供“同意并不再提示”，仅记住当前服务、完整地址、协议与模型。重启后仍生效，切换到新目标重新确认。通用设置中的“恢复远程发送确认”立即清除所有桌面授权，不要求保存并应用，也不丢弃当前编辑草稿；下次远程发送重新询问。浏览器扩展保持独立授权。

这项兼容更新保留 schema 16，仅增加可选的 `remoteCaptureApprovals` 目标摘要字段；旧配置默认未授权，不主动重写配置，不触碰已有密钥或保存截图/文字。

## 密钥和草稿

各服务使用独立密钥引用，包含服务标识和目标地址摘要。合并管理页面不改变 schema 16，也不修改已有服务标识、能力记录或密钥引用。留空保留已保存的密钥，勾选删除才清除该服务的密钥。修改服务地址清空未保存的旧地址密钥，并要求新目标重新填写。密钥编辑值以密码形式显示；切换界面语言保留未保存输入。关闭窗口取消请求并清空未保存密钥。

文字与图片测试只验证当前草稿，不会保存配置。删除当前模型所在服务前，需先保存另一个当前模型或清空选择。配置写入失败会恢复原密钥，不改其他服务账号。
