# 桌面二维码解析

日期：2026-09-28。本功能属于桌面“截屏释义”，与已冻结的浏览器插件独立。

## 使用

1. 在主页或托盘菜单点击 **解析二维码**。
2. 框选屏幕上的完整二维码，尽量保留四周留白。
3. 在结果卡中查看原始内容。多个不同内容的二维码可通过编号切换，“复制”复制当前项，“复制全部”复制所有项。
4. HTTP/HTTPS 网址显示 **在浏览器打开**，点击后交给系统默认浏览器。不需要手工复制粘贴。

已有截图结果卡也提供“解析二维码”，可复用同一张截图。非网址内容（普通文字、Wi-Fi、名片、自定义协议等）可以查看／复制，不自动执行。识别完成本身不会自动打开网页。无法打开浏览器时保留网址并提示手动复制。

二维码解析不使用 OCR、翻译或大模型，不读取 API 凭据、不上传截图、不启动模型。解码器支持中文、旋转、反色以及多个二维码；同一内容的重复二维码合并显示。截图和结果仅在现有结果卡会话内存中处理，不写历史或日志。截图本身仍遵循现有 Windows／Linux 捕获机制；Wayland 继续使用系统截图门户。

## 实现

- Core：`IQrCodeDecoder`、`QrCodeResult` 及 HTTP/HTTPS 链接分类。
- Infrastructure：`ZxingQrCodeDecoder`，ZXing.Net 0.16.11 + 既有 SkiaSharp，全托管二维码解码，图像处理放到后台线程。
- App：在进入任何 OCR／翻译／视觉服务前分流二维码任务，复用截图、裁剪、取消和结果卡生命周期。
- 浏览器跳转：完整网址经过校验后使用系统 Shell 默认处理程序，仅在点击按钮时发生；失败不输出网址或异常正文。
- 保留原有 Native Messaging 主机与当前用户命名管道；没有新增网络监听端口。

## 验证

本次已通过 321 项 .NET 测试（Core 254、App 67），其中新增 22 项二维码解码／网址分类测试和 4 项结果卡测试；Python 引擎 29 项、脚本 31 项通过。测试覆盖中文、90 度旋转、黑白反色、混合反色的多码、空图、无效图、取消、非网页协议、选择切换、旧链接清理、打开失败及中英界面切换。

Windows 原生桌面验证使用合成二维码，实际执行生产代码的屏幕捕获 → 鼠标拖动框选 → 内存裁剪 → 本地解析 → 结果卡，再点击真实“在浏览器打开”按钮。默认浏览器访问本机临时 HTTP 测试页成功。未保存实际桌面全屏截图、用户内容或凭据。结果卡及主页另有浅深色／中英文合成界面检查。二维码未在 Ubuntu 实机做桌面操作验收。
