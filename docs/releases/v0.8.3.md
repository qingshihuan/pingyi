# 截屏释义 v0.8.3 — 第三方模型 API

## 第三方模型服务接入

在 **设置 → 自定义接口** 新增 OpenAI 兼容 API 服务商预设：

- OpenAI
- DeepSeek
- SiliconFlow
- OpenRouter
- 阿里云百炼 / DashScope
- 智谱 BigModel

选择服务商后可将接口地址填入配置表单。用户仍需填写服务商提供的准确模型 ID 和 API Key，再主动保存并测试；应用预设不会自动发起网络请求，也不会替用户猜测模型名称。其他 OpenAI Chat Completions 兼容端点仍可手动填写。

## 支持的任务

沿用已有的 Chat Completions 兼容客户端，支持：
- 第三方模型文字翻译；
- 支持 OpenAI `image_url` 输入的多模态模型执行截图 OCR；
- 图片描述；
- 提示词反推。

远程视觉任务需在“文字识别”中选择兼容多模态大模型 OCR，并确认所选模型具备视觉输入能力。纯文本模型不能执行图片任务。当前不支持原生 Anthropic Messages 协议或要求专有签名的 API。

## 安全与隐私

- API Key 继续保存在操作系统安全存储中，通过 Bearer Authorization 发送；不写入 settings.json 或日志。
- 远程 API 强制 HTTPS；拒绝在 URL 中嵌入用户名、密码或密钥。
- 远程翻译会将识别后的文本发送给所选服务商；远程 OCR、图片描述和提示词反推会上传本次选择的截图。服务商可能按请求、Token 或图片计费，其数据保留、训练与地区政策由服务商决定。
- API Key 输入框由兼容端点共用。切换服务商时请替换成对应服务商的密钥。
- 选择服务商预设只填充端点并选择兼容翻译提供商；不会自动上传内容。用户必须主动保存和测试。

## 本版保留

本次不移除本机 llama.cpp / Ollama / LM Studio 等兼容端点，不改变轻量模式、基础模式、Vulkan 默认后端、CPU 模式、手动显卡选择或本地模型配置。无需因启用第三方 API 而卸载本地模型。

## 升级说明

升级前请从托盘选择“退出并释放资源”，再安装 v0.8.3。现有用户配置与模型目录保留。远程 API 使用者需自行向服务商申请 API Key，并确认模型 ID、地区可用性、配额和计费方式。

## English

v0.8.3 adds provider presets for OpenAI, DeepSeek, SiliconFlow, OpenRouter, Alibaba Cloud Model Studio (DashScope), and Zhipu BigModel. Users enter the exact model ID and API key, then explicitly save and test. The existing OpenAI Chat Completions-compatible client supports text translation and, when the selected model accepts `image_url`, multimodal OCR, image description, and prompt reconstruction.

API keys remain in the OS secure store and are sent as Bearer credentials. Remote endpoints require HTTPS and reject URL-embedded credentials. Remote translation uploads recognized text; vision tasks upload the selected screenshot and may incur provider charges. Native Anthropic Messages and proprietary signed APIs are not supported. Local model services, Lightweight mode, Vulkan/CPU and existing runtime settings remain available.
