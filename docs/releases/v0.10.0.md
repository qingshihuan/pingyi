# 截屏释义 v0.10.0 — 统一多模态模型与一键本地配置


本版将截图识字、翻译、图片描述和提示词反推统一到一个当前多模态模型，并改进本地模型配置、运行状态刷新和远程发送确认。

## 安装包

- Windows 10/11 x64：`PingYi-Complete-0.10.0-win-x64-setup.exe`；免安装压缩包为 `PingYi-Complete-0.10.0-win-x64.zip`。
- Ubuntu x64：`PingYi-Complete-0.10.0-linux-x64.deb`，或 `PingYi-Complete-0.10.0-linux-x64.tar.gz`。
- `SHA256SUMS.txt` 提供四个安装包的校验值。

安装包包含 .NET 运行环境、llama.cpp CPU/Vulkan 后端和许可证，不包含模型权重或 API Key。模型仅在用户主动开始配置或下载时获取；其他显卡后端可按需安装。

## 模型与设置

- 只有已通过图片输入和文本输出测试的模型才能设为当前模型；纯文本模型和仅获取到列表的模型不能选中。
- 设置分为当前模型、API 模型管理、本地模型管理、快捷键和通用设置。
- API 模型管理统一连接云端服务及已有的 llama.cpp、Ollama、LM Studio、vLLM 等本地 API，本地地址预设带“（本地）”标记。
- 本地模型管理独立负责软件内置的模型下载、后端安装、显卡选择和启停。外部 API 服务的进程由原应用管理。

## 一键本地配置

- 配置向导和本地模型管理均加入“一键检测并自动配置”，涵盖硬件检测、后端准备、模型复用或下载、图片/文字验证及保存当前模型。
- 自动检测为默认后端策略：有可用显卡时使用显卡，显卡后端无法使用或推理验证失败时尝试 CPU。已有明确保存的后端选择继续保留。
- 配置过程显示进度，支持取消和失败重试；验证成功后才保存。其他页面尚未保存的 API、密钥和通用设置草稿会保留。
- 内置 CPU/Vulkan 版本仍为已固定并校验的 b11146；主动在线安装后端时解析上游最新稳定版本，不将内置版本冒充最新版本。

## 状态与发送确认

- 首页及运行状态详情在配置保存后立即刷新，窗口可见时每两秒检查本地状态。
- API 的“已验证”表示图片与文字能力测试结果已保存，不代表实时联网或额度检查；状态刷新不会调用 API 或启动模型。
- 截图识字/翻译和图片分析弹窗新增“同意并不再提示”。记住的授权绑定服务、地址、协议与模型，重启后仍有效；新目标需重新确认。
- “通用设置 → 恢复远程发送确认”可立即清除记住的授权。取消和仅同意本次仍可用，浏览器扩展保留独立授权。

## 移除及兼容性变化

- 移除 PaddleOCR、百度云 OCR、Google Cloud Vision 及传统 OCR 配置、依赖和代码。
- 移除轻量模式、按任务独立绑定模型、传统 OCR 纠错链和翻译回退，以及 Python/Argos/CTranslate2 推理宿主。
- 自动截图先尝试本地二维码解析，无二维码时使用当前模型识字和翻译。二维码不需要模型，也不会自动打开链接。
- 请求失败不会静默改用其他模型或云端服务。

## 升级与数据保护

1. 从托盘选择“退出并释放资源”，备份现有配置与密钥后安装新版。
2. 配置升级至 schema 16；首次保存前保留 `settings.json.pre-v16.bak` 原始备份，已有备份不覆盖。已使用 schema 16 的测试版可直接升级。
3. 保留服务标识、已有本地密钥存储方式、语言及快捷键，不强制引入新凭据库；不会覆盖本地密钥或删除已下载模型。
4. 旧版不同任务使用不同模型，或模型能力尚未验证时，需要重新选择并验证一个当前模型。原配置可通过备份恢复。

完全版继续使用原有数据目录；历史标准版的独立目录不会自动合并。截图与识别、翻译结果仅保留在内存，不增加持久历史。远程请求会向所选服务发送截图或文字，服务商可能收费并适用其数据政策。

## 验证与已知限制

- 566 项本地自动测试通过；主线 Windows/Ubuntu CI 通过，涵盖 Linux X11 与截图 portal 原生检查。
- 发布流程再次运行双平台测试，审计依赖、许可证、源代码和解包内容中的敏感信息，并在干净的 Ubuntu 22.04/24.04 环境验证 Debian 包。
- 本地 Windows 鼠标自动点击工具受桌面合成环境限制，未完成最后一次原生点击验证；弹窗按钮、布局、授权持久化及恢复提示已通过自动化测试。
- 模型能力测试验证合成内容，不保证所有截图的识别质量；GPU 驱动、显存和具体服务权限仍以用户设备和账号为准。

## English

v0.10.0 uses one verified multimodal model for screenshot recognition, translation, image description and prompt reconstruction. Local deployment is separate from the unified local/cloud API editor. One-click setup is available in both onboarding and Local models, with GPU-first automatic selection and CPU fallback. Status refreshes automatically, and remote-transfer dialogs can remember approval for a specific destination and model, with a reset action in General settings. Traditional OCR engines, lightweight mode, per-task routing and Python translation runtimes are removed. Schema 16 preserves existing keys and settings with a non-overwriting migration backup. Packages include CPU/Vulkan runtimes and licenses, but no model weights, private configuration or credentials.
