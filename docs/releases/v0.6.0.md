# 截屏释义 0.6.0 — 本地二维码解析与新品牌

## 桌面更新

- PingYi／屏译正式更名为 **截屏释义（Screen Insight）**，涵盖截图翻译、图片描述、提示词反推和二维码解析。沿用原完全版配置、模型目录和凭据存储。
- 使用定稿的蓝、橙、白图标，四角边框与右侧图形为黑色；桌面窗口、托盘、安装展示名称同步更新。
- 主页、托盘菜单和截图结果卡新增 **解析二维码**。框选完整二维码后即可查看原始内容，支持中文、旋转、反色和同一截图中的多个二维码。
- 二维码中的 HTTP/HTTPS 网址提供 **在浏览器打开**，点击后交给系统默认浏览器；其余内容可复制，不自动执行。识别结束不会自行打开网页。
- 二维码完全本地解析，不需要 OCR 引擎、大模型或 API，不启动模型、不上传截图、不增加内容历史。新增 ZXing.Net 0.16.11（Apache-2.0），发行包包含对应许可文本。

## 浏览器插件状态

浏览器插件暂时冻结开发。保留已有 0.1.1 源码及桌面 Native Messaging／本机命名管道连接能力，不增加 TCP 监听端口，不继续新增插件功能或推进扩展商店上架。插件作为可选开发组件保留，**本次桌面安装包不自动安装插件或注册原生主机**；已有本地连接组件可继续配合新版桌面端使用。需要自行构建时参考仓库 `browser-extension/README.md`。

## 下载与升级

**取消标准版，仅保留完全版。**提供 Windows x64 安装程序／ZIP、Linux x64 DEB／tar.gz，共 4 个程序包及 `SHA256SUMS.txt`。文件名继续使用 `PingYi-Complete-` 前缀，软件内显示新名称；源码直接运行也启用完全版功能。

升级前退出旧版托盘程序。沿用原完全版的安装、模型和数据目录。旧标准版数据保留在原目录，不会自动迁移或删除；切换到完全版后需重新配置服务与凭据。已有插件连接时请选择“完全版”。完全版不附带大模型权重；基础离线 OCR／中英翻译模型继续随正式程序包提供。

## 验证范围

本地已通过 321 项 .NET 测试、29 项 Python 引擎测试、31 项脚本测试；已用合成二维码在 Windows 上实际执行屏幕捕获、拖动框选、内存裁剪、二维码解析和默认浏览器跳转。检查了结果卡和主页的中英／浅深色界面。

发布流程在 Windows 和 Ubuntu 上重新构建、测试、收集许可证并审计依赖，完成两平台完全版打包；以对应 GitHub Actions 结果和本 Release 实际附件为准。物理 Ubuntu 桌面的二维码框选、默认浏览器跳转，以及混合 DPI 多屏尚未实机验收，不把无头界面测试当作这些场景已验证。

## English

PingYi is now **Screen Insight** (截屏释义), with updated blue/orange/white/black branding and compatible existing Complete settings, model paths and credential storage.

The desktop app adds fully local **Read QR code** actions on the home screen, tray and result card. Decode text or multiple QR codes without OCR models, AI services or uploads. Explicit HTTP/HTTPS URLs offer **Open in browser**, which uses the system default browser only when clicked. Other payloads remain copyable text. ZXing.Net 0.16.11 is included under Apache-2.0.

Browser extension development is frozen. Its existing source and local desktop bridge remain available, but the desktop installers do not install the extension or register its native host. Standard is discontinued; only Complete is built and released, with four application packages plus checksums. Package filenames keep the PingYi-Complete prefix for compatibility. Complete retains its existing data directories. Legacy Standard data is not deleted or automatically migrated; configure services and credentials again after switching. Select Complete in an existing browser extension. Exit the previous tray instance before upgrading.
