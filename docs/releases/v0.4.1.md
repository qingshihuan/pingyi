# 屏译 PingYi v0.4.1

修复 v0.4.0 的五项使用问题，整合已合并的 PR #17。保留现有原生视觉、离线 OCR / 翻译和启动 / 资源优化；本次不更换模型、不增加生产运行依赖，也不覆盖 v0.4.0 的附件。

## 五项修改

### 单一主界面

删除“新版 / 经典完整界面”选择、经典入口和旧窗口类，只保留统一的现代主窗口及独立设置窗口。设置 schema 更新至 8：读取旧设置时忽略 interfaceStyle，正常保存时不再写入该字段，其他偏好和安全存储中的凭据不重置。

### 多显示器截图隔离

截图前统一隐藏原本可见的屏译窗口，包括设置、帮助、方案选择和固定结果窗口；关闭下拉框，排空 UI 队列并等待桌面呈现后再抓取底图、创建框选层。Windows 临时抑制自身窗口过渡动画，并在 Windows 10 2004+ 临时排除自身窗口捕获；结束后恢复原生标志和原窗口状态。完成、Esc、任务取消和错误使用统一清理路径，退出时不重新显示窗口。保留负坐标、跨屏和混合 DPI 的几何处理。

这是针对主界面虚影的代码修复，尚未在用户的物理多显示器、混合缩放 / 刷新率和显卡驱动组合上完成最终验证。DwmFlush 不是整个桌面合成会话的完成保证，实机复核步骤见仓库 docs/USABILITY_FIXES.md。

### 中英文即时切换

在“设置 → 外观与启动 → 界面语言”选择 English 或简体中文后，先单独保存语言偏好，成功后立即更新已打开的窗口和托盘，无需重启；保存失败会回滚选择。主窗口、设置、结果、框选层、方案窗口和帮助页使用动态中英文资源。不重建其他输入框，不清空未保存的密钥、快捷键或模型名，不翻译用户原文、译文和接口地址。第三方服务返回的未知错误可能仍保留提供商语言。

### 可读的方案比较

以可滚动的独立方案窗口替代紧凑下拉菜单。每项分行说明名称、处理方式、用途和条件，底部“应用 / 取消”固定，选中后确认才应用。离线基础、大模型翻译、视觉纠错、百度云服务和自定义组合均对应真实提供商；大模型方案保留已配置接口和模型，并按实际本机回环 / 远程地址解释联网与上传范围。自定义组合只打开配置，不擅自更换引擎。不承诺未经验证的高精度、表格或公式能力。

### 主页与帮助重组

主页移除隐私边界卡，聚焦截图、当前方案、OCR / 翻译状态和基础模型。新增“帮助与关于”，展示实际应用版本、真实快捷键、使用方法、当前配置的数据去向及仓库链接。

## 其他修复

修复设置底部状态提示、部分结果提示因主题画刷解析为空而不可见的问题，支持正常 / 错误状态和浅深主题切换。按需模型提示不再无条件声称基础模型已验证。没有加入网页外壳、实时模糊、持续动画循环、遥测或截图 / 翻译历史。

## 验证范围

PR #17 的 Windows / Ubuntu CI #104 已通过构建和自动回归，包含语言下拉真实事件、JSON 持久化、窗口即时刷新、保存失败回滚、用户输入保留、旧配置迁移、方案路由、最小窗口换行、截图隐藏 / 等待 / 捕获 / 恢复顺序及主题状态显示。

本次发布流程重新执行全套测试、Windows OCR 质量基线、成品依赖及许可证审计，以及干净 Ubuntu 22.04 / 24.04 容器的 Debian 包安装检查；只有双平台构建成功、八个成品全部收齐后才发布。界面渲染和自动测试不能替代用户桌面的物理多屏、系统全局热键、系统安全存储及完整业务验收。

## English summary

PingYi v0.4.1 integrates PR #17: one modern main interface, capture-time isolation of all visible PingYi windows, immediate persisted language switching with rollback, a readable mode-comparison window, and a dedicated Help & About page for privacy and usage information. It also fixes invisible status feedback in light and dark themes. Existing preferences, credentials, offline models and runtime resource optimizations are retained. Physical multi-monitor ghosting verification remains hardware-dependent and is documented in docs/USABILITY_FIXES.md. Windows x64 and Ubuntu X11 x64 Standard / Complete packages are accompanied by SHA-256 checksums.
