# 截屏释义 v0.9.0 — 配置中心重构

## 配置中心

v0.9.0 将原先分散的模型与运行设置整理为统一配置中心，围绕“服务档案、模型能力、任务路由、运行环境”管理软件配置。

### 多服务档案

- 可同时保存多个本地和远程模型服务，不再要求不同服务商共用同一组地址与模型字段。
- 每个服务档案独立保存服务类型、端点、协议、模型配置和凭据引用。
- API 密钥继续保存在操作系统安全存储中，配置文件只保存凭据引用，不写入明文密钥。
- 继续支持 OpenAI Responses API、OpenAI Chat Completions 及第三方 Chat Completions 兼容服务。
- 本地 llama.cpp、Ollama、LM Studio 和现有 Vulkan / CPU 运行环境继续可用。

### 按任务选择模型

可以分别为以下任务选择服务和模型：

- 文字 OCR
- 文字翻译
- 图片描述
- 提示词反推

每个任务的服务与模型选择互相独立。二维码继续使用本地解析，不需要调用远程大模型。配置概览显示任务当前绑定的服务、模型和数据处理目的地。

### 模型管理与能力检测

- 按服务发现和刷新可用模型。
- 区分文字与图片输入能力。
- 修改服务端点、协议、密钥或模型后，旧的能力测试状态会失效，需要重新验证。
- 模型列表存在不代表模型已通过实际推理测试；视觉能力应通过图片测试确认。
- 服务未指定模型时，明确使用服务端默认模型。

### 运行环境与隐私

- 本地 GPU 后端和设备选择继续独立于云端 API 服务配置。
- 保存配置不会提前启动本地模型或占用显存。
- 远程翻译会向所选服务商发送识别文本；远程视觉任务会发送所选截图，可能产生服务费用。
- 远程 API 继续要求 HTTPS；凭据保存在系统安全存储。

## 配置迁移与升级

- 配置 Schema 更新至 15。
- 从旧版本升级时自动迁移已有服务、模型、任务行为、快捷键和运行后端设置。
- 首次迁移前保留 `.pre-v15.bak` 备份。
- 不要求重新下载已安装的模型。
- 建议升级前从系统托盘选择“退出并释放资源”，再安装 v0.9.0。

## 当前范围说明

本版交付配置中心、多服务档案、任务级服务/模型绑定、配置迁移与能力状态管理。快捷键、网络下载、诊断和部分高级设置继续沿用现有页面；完整的分步首次启动向导、自动最佳模型选择和跨服务自动故障转移尚未纳入本版。

## English

v0.9.0 refactors PingYi settings into a configuration center with independent local and remote service profiles, per-task model routing for OCR, translation, image description and prompt reconstruction, model discovery/capability validation, isolated OS-secure credential references, and schema migration from existing settings. QR parsing remains local. OpenAI Responses, Chat Completions-compatible providers, local llama.cpp/Ollama/LM Studio, Vulkan and CPU workflows remain supported. Existing user settings and model files are preserved; migration creates a `.pre-v15.bak` backup. Remote translation sends recognized text and remote vision tasks send the selected screenshot to the configured provider and may incur charges. The full first-run wizard and automatic cross-provider failover are not included in this release.
