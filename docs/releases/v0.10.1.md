# PingYi v0.10.1

## Improvements
- Reduced the fixed pre-capture wait on Windows and use the DWM compositor flush as the presentation barrier.
- Removed the additional fixed delay after the compositor flush.
- Added privacy-safe capture timing diagnostics to help identify latency across the capture pipeline.

## Compatibility and safety
- Every capture still obtains a fresh desktop frame.
- Existing window hiding/restoration and cancellation behavior is retained.
- The conservative non-Windows capture wait remains unchanged pending platform-specific desktop measurements.

## Validation
- GitHub Actions CI passed on Windows and Ubuntu for the release candidate.
- End-to-end interactive desktop latency (P50/P95), multi-monitor, and mixed-DPI measurements were not available in CI and should be validated on target machines.
