# PingYi v0.5.1

## 本次修复

- 修复旧版、不完整或含 `null` 字段的配置导致启动初始化失败，继而出现“窗口可以打开，但截图服务尚未初始化”的问题。缺失模型名称恢复默认值；显式空模型、自定义服务端点、语言、快捷键和启动偏好保持兼容。
- Linux 默认截图快捷键改为 `Ctrl+Alt+Shift+D`。仅迁移旧版 Linux 默认快捷键，不覆盖用户自定义快捷键；Windows 默认仍为 `Ctrl+Alt+D`。
- 修复 X11 快捷键冲突时可能被 Xlib 直接终止进程的问题。冲突提示保留，用户仍可通过主界面截图按钮操作。
- Wayland 截图改用 XDG Screenshot portal 的系统选择/授权流程，不读取 XWayland 根窗口，也不再次按 X11 坐标裁剪系统返回的图片。
- 修复首次以 `--capture` 启动时截图命令被忽略的问题；保留向已运行实例转发命令的行为。
- 截图取消或失败后恢复主窗口；补充 Linux 桌面菜单截图入口和系统依赖说明。

## 使用说明

X11 会话可使用应用注册的快捷键，或者点击“开始截图”。Wayland 的全局快捷键由桌面系统管理，请在系统键盘设置中绑定应用设置页提供的截图命令；本版本不会私自修改 Ubuntu 的系统快捷键。

普通版和 Complete 版均提供 Windows x64 安装程序/便携 ZIP，以及 Linux x64 DEB/tar.gz。Release 附带 `SHA256SUMS.txt`；Complete 版的大模型权重仍按需下载，不包含在安装包内。

## 回归检查与边界

自动化检查覆盖 Windows/Ubuntu 构建、.NET 单元和 UI 测试、Python 引擎/打包脚本测试，以及空配置、缺失字段、显式 null、显式空模型的保存/重载兼容。

Linux 原生检查在隔离的 Xvfb/Openbox 和私有 D-Bus 会话中执行：X11 快捷键冲突与触发、屏幕像素读取、GIO 门户响应/取消/关闭；真实 Avalonia 进程执行首次 `--capture`、主窗口真实鼠标点击、二次进程命令、快捷键进入框选和 Esc 恢复。

Xvfb 和模拟门户不是物理 Ubuntu GNOME/Wayland 实机验收。真实桌面门户授权、多显示器/混合 DPI、不同显卡环境以及真实视觉模型输出仍取决于具体桌面与硬件，不将自动化通过表述为这些组合已全部验证。

## English summary

Fix initialization with incomplete or null legacy settings; restore working capture entry points; use a Linux-specific default hotkey; handle X11 shortcut conflicts without terminating the app; use the system screenshot portal on Wayland; and honor first-process `--capture`. Custom preferences are preserved. Native automated checks use an isolated synthetic desktop and are not a substitute for physical GNOME/Wayland, multi-monitor or GPU validation.
