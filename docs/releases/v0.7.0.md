# 截屏释义 v0.7.0 — 一键识别与基础／轻量模式

## 一次截图，自动选择任务

主按钮和默认截图快捷键改为 **一键识别（Smart capture）**。截图后在本地探测二维码和文字，推荐文字翻译、图片描述或二维码解析。二维码与明显正文混合、证据不足或探测失败时提示手动选择；OCR 返回空结果只作为图片描述的候选依据，不等于证明没有文字。

**手动选择始终保留。**截图前可直接指定文字翻译、图片描述、二维码解析或提示词反推；结果页允许处理中改选，复用同一张截图并取消旧任务，防止旧结果覆盖新选择。关闭主页的“自动判断任务”后，主按钮和快捷键恢复直接文字翻译。自动开关会保存，明确关闭的设置不会在重启后被重新开启。

自动探测只使用本地二维码解码与 PaddleOCR，不为判断任务调用云端或大模型，也不会自动下载模型。二维码网址仅在用户点击后打开，其他载荷不自动执行。

## 基础模式与轻量模式

- **基础模式：本地自定义大模型 OCR → 本地自定义大模型翻译。**直接使用支持图片输入的本机模型，不再传入 PaddleOCR 初稿；新安装默认选择该组合。
- **轻量模式：PaddleOCR → Argos Translate。**原离线基础流程更名为轻量模式，保留无需大模型的中英离线能力。
- 删除 **PaddleOCR + 大模型纠错**提供商和 **视觉纠错**方案，以及对应的初稿调用和纠错提示词。PaddleOCR 本身继续用于轻量模式、本地任务探测和独立的 OCR → 大模型翻译组合；后者不是视觉纠错。
- 基础模式名称仅匹配本机回环端点。其他自定义／云端组合继续保留，不会为了切换模式覆盖用户配置的远程端点。

## 首次使用引导

新安装首次进入提供 **一键下载并配置、连接已有本机服务、使用轻量模式** 三条路径，并展示模型来源、下载量、许可与设备提示。只有用户点击下载才访问现有固定 ModelScope 模型目录；完成下载、校验、启动和固定合成图片／短句连接检查后，才保存模型与基础组合。

下载取消或失败不会标记配置完成，可继续重试和断点续传。没有内置运行时的源码运行环境会明确提示安装完整程序包或连接已有服务。主界面保留“模型配置引导”入口，已有用户也可重新进入。

## 升级兼容与隐私

配置升级至 schema 11。已有 OCR／翻译组合、端点、模型、语言、快捷键和凭据保持兼容；旧 `local-vlm-corrected` 迁移到直接视觉 `local-vlm-ocr`，不强制改变翻译提供商。旧配置缺少提供商字段时继续使用历史 PaddleOCR／Argos 默认，不被新安装默认覆盖。已有用户不会被强制弹出首次引导。

自动任务需要远程 OCR／文字翻译时，先确认本次接收方；自定义请求使用配置快照。图片分析保留逐次上传确认。截图、探测与结果只在当前内存会话中处理，不增加磁盘历史、内容日志或遥测。

## 下载与安装

继续仅发布 **完全版（Complete）**，不重新拆分标准版／轻量安装包。“轻量”是同一程序内的处理模式。

提供 Windows x64 安装程序和便携 ZIP、Linux x64 DEB 和 tar.gz，共 **4 个程序包及 SHA256SUMS.txt**。程序包前缀仍为 `PingYi-Complete-`，沿用完全版安装、模型和配置目录；升级前退出旧版托盘进程。大模型权重不包含在安装包中，需要用户主动下载；内置轻量模型仍可离线使用。

浏览器插件继续冻结开发，保留原有连接协议，不自动安装插件或注册 Native Messaging 主机。Windows／X11 快捷键及 Wayland 系统截图门户的使用方式保持不变；Wayland 全局快捷键仍需在桌面系统中绑定。

## 验证边界

回归覆盖 Windows／Ubuntu 构建、Core／App 界面、Python 引擎和脚本；Linux 原生截图检查使用隔离 Xvfb/Openbox 与私有 D-Bus 门户。新增测试覆盖自动分流、配置迁移、处理中手动改选、首次引导的取消／失败重试和自动开关保存。

**首次引导自动测试使用可替换回调，本次未完成真实 ModelScope 大模型下载及真实视觉推理的端到端验收。**用户实际下载配置时的固定连接检查不能当作完整模型质量测试。自动规则是可纠正的启发式推荐，不保证所有语言、模糊图像或混合内容都判断正确；虚拟桌面检查不代表物理 GNOME／Wayland、多屏混合 DPI 和所有显卡的实机验证。

详细说明：[一键识别与首次配置](https://github.com/qingshihuan/pingyi/blob/v0.7.0/docs/AUTOMATIC_CAPTURE.md)。

## English summary

Smart capture now recommends text translation, image description or QR decoding using local QR/PaddleOCR probes. Mixed or uncertain evidence asks for a choice. Manual tasks remain available before capture and during processing; switching reuses the same image and invalidates obsolete work. QR URLs never open automatically.

New installations default to direct local vision OCR plus local model translation (Basic). PaddleOCR/Argos remains available as Lightweight. The PaddleOCR-plus-LLM correction provider and visual-correction preset are removed. First-run setup explicitly offers a verified model download, an existing local service or Lightweight; cancellation and failure do not mark setup complete. Existing settings and Complete-edition data paths are preserved.

Only Complete packages are distributed: Windows installer/ZIP, Linux DEB/tar.gz and SHA256SUMS.txt. Model weights are not bundled. Automatic remote processing requires confirmation, and no content history or telemetry is added. Automated onboarding tests use injected callbacks; physical desktop coverage and a real model download/inference end-to-end validation are not claimed.
