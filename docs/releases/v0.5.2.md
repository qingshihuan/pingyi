# PingYi 0.5.2 — 自定义截屏快捷键

## 更新内容

- Linux 默认截屏快捷键改为 **Ctrl+Shift+D**；Windows 仍为 **Ctrl+Alt+D**。
- 在“设置 → 外观与启动”中新增“录入快捷键…”与“恢复默认”。也可继续手动输入。支持 Ctrl / Alt / Shift 与一个 A–Z 字母或 0–9 数字组合；暂不支持 Super、功能键、小键盘键。
- 录入窗口显示组合，Enter 确认、Esc 取消；只有返回设置并点击“保存并应用”后才更改绑定。录入期间暂停本程序原生全局快捷键，关闭窗口后恢复已保存的绑定；录入和保存不会并发执行。
- 沿用运行时注册冲突提示和失败回滚；快捷键不可用时，截图按钮仍可使用。
- 配置升级为 schema 10：Linux 上迁移历史默认 Ctrl+Alt+D（schema < 9）和 Ctrl+Alt+Shift+D（schema < 10），其他自定义组合与 Windows 配置保留。升级后可重新选择旧组合并保存。
- 新增按键组合、录入确认/取消、双语设置控件与配置迁移回归测试；原生 X11 测试改用 Ctrl+Shift+D。

## Linux 冲突与 Wayland 说明

Ctrl+Shift+D 未列于 GNOME 官方常用系统快捷键表，但这不保证所有 Linux 发行版、桌面环境或个人配置都未占用。Chrome 用它收藏所有标签页，Konsole 用它进入键盘选择模式；注册为全局键后可能影响这些应用内操作。遇到冲突可在设置中更换。

X11 由屏译注册全局快捷键；**Wayland 中软件内的值是偏好，不会自动修改系统绑定**。请复制“设置 → 外观与启动”中的截图命令，在桌面系统键盘设置中将所选组合绑定到该命令。Ubuntu 路径为“设置 → 键盘 → 自定义快捷键”。本版没有新增 GlobalShortcuts 门户，不把保存偏好当作已启用系统快捷键。

参考：[GNOME 快捷键](https://help.gnome.org/gnome-help/shell-keyboard-shortcuts.html)、[Chrome 快捷键](https://support.google.com/chrome/answer/157179)、[Konsole 选择模式](https://docs.kde.org/trunk_kf6/en/konsole/konsole/selection.html)。

标准版和完全版均提供 Windows x64 安装程序 / ZIP、Linux x64 DEB / tar.gz；以本 Release 实际附件为准，SHA256SUMS.txt 用于校验。没有新增运行时依赖、模型或截图历史。

## English

Linux now defaults to **Ctrl+Shift+D**; Windows keeps **Ctrl+Alt+D**. Settings → Appearance & startup adds a shortcut recorder and Restore default. Confirm the recorded combination, then Save to apply it. Recording temporarily suspends PingYi's own native shortcut and restores the saved binding afterwards. Other custom combinations are preserved across the schema-10 upgrade; known historical Linux defaults are migrated.

On Wayland this setting stores a preference only: bind the capture command in your desktop's keyboard settings. Personal desktop bindings and application shortcuts (including Chrome and Konsole) may conflict. This release does not claim universal conflict freedom or physical GNOME/Wayland verification.
