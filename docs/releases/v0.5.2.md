# PingYi v0.5.2

## 截图快捷键

- Linux 默认截图快捷键改为 **Ctrl+Shift+D**；Windows 保持 **Ctrl+Alt+D**。仅迁移旧 Linux 已知默认值，其他自定义组合保留；新增显式自定义标记，避免后续升级误迁移。
- 在 **设置 → 外观与启动** 增加 **录入快捷键** 和 **恢复默认**。支持手动输入，或按 Ctrl/Alt/Shift 加一个 A–Z / 0–9 键录入；Esc 取消，松开全部按键完成录入，点击“保存并应用”生效。
- 录入期间暂时释放屏译自己的全局绑定，结束或取消后恢复，避免录入原快捷键时误触发截图。
- 保存前校验格式并尝试绑定；冲突或持久化失败时恢复旧绑定，失败提示保持可见，截图按钮仍可使用。主窗口和托盘在成功保存后更新，重启保留自定义组合。
- 修饰键顺序、大小写及 Control/Ctrl 统一规范化；拒绝重复修饰键、空分段、多个主键等歧义输入。

## Linux 提示

Ubuntu/GNOME 官方常用系统快捷键表未列出 Ctrl+Shift+D，不代表所有发行版、扩展及个人配置都无冲突。Chrome 用此组合收藏所有标签页，全局截图绑定可能覆盖该操作。X11 以实际注册结果检测全局占用。

**Wayland：应用内保存的是首选组合。仍需复制设置页的截图命令，在桌面系统的自定义快捷键中绑定同一组合。屏译不会自动修改系统设置，也不会把保存首选项宣称为系统已注册成功。**

完整操作、迁移说明与官方资料见 [快捷键说明](../HOTKEYS.md)。旧配置无法区分曾手动选成旧默认值的情况；这种情况需要重新设置一次。

## 验证与发行

回归覆盖设置迁移、配置重载、解析校验、绑定/保存失败回退、录入取消恢复，以及 Windows/Ubuntu 的构建和 UI 测试。Linux 原生自动化在隔离的 Xvfb/Openbox 中实际打开软件，通过键盘和鼠标录入、保存、触发截图、重启并恢复默认；截图门户检查继续使用私有 D-Bus fixture。

这些自动化不等于物理 GNOME/Wayland、多显示器/混合 DPI、不同显卡组合的实机验收。

普通版与 Complete 版各提供 Windows x64 安装程序/ZIP、Linux x64 DEB/tar.gz，共 8 个安装包及 SHA256SUMS.txt。

## English

Linux now defaults to Ctrl+Shift+D; Windows keeps Ctrl+Alt+D. Record, type or restore a capture shortcut in Settings → Appearance & startup, then Save and apply. Recording temporarily releases the application's active binding; cancellation restores it. Invalid input is rejected and failed binding/persistence attempts restore the prior shortcut where possible. Custom choices survive restart. On Wayland, separately bind the supplied capture command in desktop settings. Chrome's bookmark-all-tabs action uses the same Linux default, so choose a different combination to retain that application shortcut. Native automation uses a synthetic desktop, not physical Wayland or mixed-DPI hardware.
