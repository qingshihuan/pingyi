# PingYi v0.5.2

## Linux 默认截图键

Linux 默认截图快捷键调整为 **Ctrl+Shift+D**，Windows 继续使用 **Ctrl+Alt+D**。Ubuntu/GNOME 官方常用默认系统快捷键表没有列出该组合；仍可能与用户自定义绑定或应用内操作重叠，例如 Firefox 的“收藏所有标签页”。应用时检查当前全局注册占用，不承诺所有 Linux 配置和应用都无冲突。

## 自定义快捷键

在 **设置 → 外观与启动 → 截图快捷键** 中，可直接输入或点击“录制快捷键”，支持 Ctrl/Alt/Shift 加一个字母或数字。新增格式检查、录制取消、恢复默认与独立“应用快捷键”入口。录制时暂停屏译自己的全局快捷键，松开主键后恢复；Esc、Tab、失焦或关闭窗口会取消并恢复原组合。

新键注册成功后才保存；占用或写入失败时恢复旧键，恢复失败明确报告。应用后立即更新主窗口与托盘提示，并在重启后保留。恢复默认先改变待应用值，点击应用后才生效。截图按钮不依赖快捷键成功注册。

## 升级与 Wayland

Schema 10 只迁移已知旧 Linux 默认，保留其他自定义组合及模型、端点、语言和启动设置。旧版本未记录“显式选择与默认完全相同的组合”的意图，无法区分这一情况；新版本记录显式自定义标记。

Wayland 页面可保存偏好组合，并提供当前版本的 `--capture` 命令。**实际全局绑定仍需在系统键盘设置中完成**；不会擅自修改系统绑定，也不把偏好保存称为系统注册成功。本版未实现 GlobalShortcuts portal，继续使用已有 XDG Screenshot 门户截图。

## 分发与验证边界

普通版与 Complete 版均提供 Windows x64 安装程序/便携 ZIP，以及 Linux x64 DEB/tar.gz，共 8 个包，附 `SHA256SUMS.txt`。本次不增加运行时依赖，不改变默认离线 OCR/翻译，不记录键盘历史或截图正文。

测试覆盖双平台构建和 Core/UI/Python 回归；Linux 专项使用真实 X11 注册与隔离 Xvfb/Openbox 应用进程检查改键、占用回滚、旧键释放、重启持久化和默认恢复。合成桌面及模拟门户不等同于所有物理 GNOME/Wayland、多屏、键盘布局或显卡环境的实机验收。

操作、迁移细节和默认键来源见 [自定义快捷键说明](../HOTKEYS.md)。实际 CI 结论和分发附件以本次工作流及 Release 为准。

## English summary

Linux now defaults to Ctrl+Shift+D, while Windows keeps Ctrl+Alt+D. Settings adds shortcut recording, cancellation, validation, reset and independent apply. Native registration precedes persistence and failures restore the previous binding. Custom settings survive restarts; known legacy Linux defaults migrate. Ctrl+Shift+D can overlap with application-local shortcuts such as Firefox's Bookmark All Tabs.

Wayland stores a preferred combination only: bind the copied capture command in desktop keyboard settings. No GlobalShortcuts portal or automatic system-keyboard edits are introduced. Default offline processing, privacy behavior and runtime dependencies are unchanged. Synthetic desktop checks are not physical GNOME/Wayland or hardware certification.
