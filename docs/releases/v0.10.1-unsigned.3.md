# 截屏释义 v0.10.1-unsigned.3 — 截图启动性能优化

本次为 **Windows 未签名预发布**，包含主线已合并的截图性能优化（PR #36）。可信签名尚未接入，Windows 可能仍显示“未知发布者”。本版本不替代稳定版。

## 改进

- Windows 截图框直接使用最新的 BGRA 原始像素，去掉整桌面 PNG 压缩和多屏重复编解码；框选完成后仅编码所选区域。
- 使用合成像素预热 XAML、字体及渲染资源；多屏截图只激活一个窗口，减少重复焦点切换。
- 隐藏应用窗口后确认原生窗口状态，并使用 DWM 同步；DWM 不可用时保留回退等待。Linux 原有同步策略保持不变。
- 新增从快捷键/按钮触发到渲染完成的分阶段计时，区分窗口 Opened、首次完成渲染与全部窗口可交互。日志仅包含时间、尺寸、数量等元数据，不记录截图、文字、路径或密钥。

## 实测与验证

三屏 7680×2160、100%/150% 混合缩放环境下，优化前 12 次、优化后 30 次测试：

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 所有屏幕首次渲染 P50 | 1650ms | 193ms |
| 所有屏幕首次渲染 P95 | 1801ms | 233ms |
| 第一次截图首次渲染 | 1774ms | 322ms |
| 全部截图框可交互 P50 | 1698ms | 242ms |

这是软件触发的真实桌面采集链路测量，并非物理按键到屏幕显示的完整测量；不同机器和负载会影响结果。本地测试安装包已完成试用，反馈截图启动速度明显提升。详细方法与限制见[性能报告](https://github.com/qingshihuan/pingyi/blob/main/docs/CAPTURE_PERFORMANCE.md)。

Windows/Ubuntu CI 覆盖构建、544 项 .NET 测试和适用的 Python 测试；另有 Windows 原生画面更新/隐藏恢复/DPI/资源释放检查，以及 Linux X11/portal、快捷键、按钮和 Esc 恢复检查。发布流程检查包内依赖、许可证和敏感信息；下载文件附带 SHA-256 校验值。

## 下载与升级

- Windows：`PingYi-Complete-0.10.1-unsigned.3-win-x64-setup.exe`；另提供便携 ZIP。
- Ubuntu X11：提供 `.deb` 与 `.tar.gz`。
- 完全退出旧版（包括托盘进程）后安装，避免仍由旧进程处理快捷键。
- 沿用现有本地配置与 API Key 存储方式，没有新增配置迁移。安装包不包含个人配置、密钥或模型权重。
- 尚待更多实机验证：模型运行负载下的完整按键延迟、物理 Linux 多屏/混合缩放、HDR、热插拔及 DWM 不可用场景。
