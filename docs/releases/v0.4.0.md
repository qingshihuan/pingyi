# 屏译 PingYi v0.4.0

新版原生界面、分类设置与结果卡，以及启动链路和后台资源优化。整合 PR #16；默认本地 OCR 与中英离线翻译保留，不更换模型或新增生产运行依赖。

## 界面与操作

- 主界面采用银白 / 石墨灰主题、蓝色主操作、轻阴影和原创矢量插画；截图按钮与当前快捷键优先展示。
- 设置改为五类侧栏：识别与翻译、本地模型、云端服务、自定义接口、外观与启动。页面独立滚动，保存和状态栏固定，切换分类保留未保存输入。
- 结果卡统一字体与主题，保留原文 / 译文选择、独立复制、复制全部、固定和重试。
- 新增 `Ctrl+,` 打开设置、`F5` 强制刷新状态、`Ctrl+S` 保存设置；默认全局截图键仍为 `Ctrl+Alt+D`。
- 保留简体中文与 English、键盘导航、焦点反馈和现有密钥显示 / 隐藏流程。
- 中文界面从主机已安装的无衬线字体中选择并缓存字体族，不下载或分发新字体。视觉风格更新不代表新增 macOS 支持。

## 启动与资源

- 现代工作台不再为启动或焦点状态检查提前加载本机多模态模型，首次截图按需启动；不再每次启动重写设置。
- 配置未变化时，被动状态检查在 30 秒内复用；手动刷新不受此限制。
- Argos 健康检查不提前导入推理组件，仍检查必要文件和 SHA-256 清单；实际翻译按需加载运行时。
- OCR 检查和推理移出 UI 线程；限制 ONNX 工作线程并关闭自旋，减少结果张量的重复复制；初始化失败时释放部分原生会话。
- Python 翻译进程闲置五分钟后自动释放，下次请求自动启动；保护运行中的任务，不强制 GC。
- 安装或清理翻译模型后刷新内部进程，下一次请求重新选择模型目录，无需重启整个应用。
- 复用已经校验且仍正常运行的自有大模型；切离托管模型方案时停止屏译自身管理的服务。完善取消、并发退出和有界错误输出处理。

## 验证与取舍

- PR 合并前的 Windows / Ubuntu CI 已通过构建、.NET 测试、Python 引擎和脚本测试；包含真实 XAML 控件渲染及布局 / 键盘回归测试。
- 发布流程另外执行全套测试、Windows OCR 质量基线、打包依赖和许可证审计，以及干净 Ubuntu 22.04 / 24.04 容器内的 Debian 包安装检查；只有双平台打包成功并收齐八个成品后才发布。
- 闲置回收后的第一次翻译需要重新加载；线程限制侧重桌面响应与资源控制，不保证所有设备单次 OCR 更快。
- 此前空模型目录下的 Python 初始化 / health 基准不等于整个桌面软件的启动、真实模型推理、总内存或显存表现，详见 `docs/PERFORMANCE.md`。
- UI 预览使用合成数据，不代表连接了真实账号或模型。自动测试不能替代用户桌面上的全局热键、密钥服务、多显示器 DPI 与真实业务端到端验收。
- 本次不引入网页外壳、实时模糊、持续动画循环、遥测或截图 / 翻译历史，不重置现有用户配置。

## English summary

PingYi v0.4.0 introduces a refined native capture workspace, five-category settings, and matching result cards in light and dark themes. It preserves the offline-first workflow while deferring managed-model startup, reducing passive health-check work, moving OCR work off the UI thread, and releasing the idle Python translation process after five minutes. First use after idle release may need to reload the engine. Windows x64 and Ubuntu X11 x64 remain the supported platforms; the visual refresh does not add macOS support. Standard and Complete installers / portable archives are accompanied by SHA-256 checksums.
