# 截屏释义 v0.8.0 — 显卡选择、运行后端管理与退出清理

## 显卡检测与执行设备

首次模型配置引导和 **设置 → 本地模型 → 显卡与运行后端** 新增本机显卡清单。展示能读取到的型号、驱动、显存等信息；缺失字段显示未知。系统显卡清单与后端实际可执行设备分开，专用后端未安装时需先安装再枚举设备。

运行后端可选 **自动、NVIDIA CUDA 12、NVIDIA CUDA 13、AMD ROCm/HIP、Vulkan、CPU**。自动模式根据架构、驱动、操作系统及实际后端检查选择候选；失败时可回退 Vulkan／CPU，并显示实际使用的后端。手动指定后端或执行显卡时不会静默换到其他设备。

多显卡选择采用 llama.cpp `--list-devices` 返回的设备名和单卡启动参数，不使用操作系统显示器顺序推测 GPU 编号。更换后端或设备时先停止本软件拥有的旧进程；检测到设备列表变化时要求重新选择。两块名称和容量完全相同的卡不能仅凭该列表证明物理身份，更换硬件或驱动后应重新检测。

## 后端下载安装与备用源

仅在用户点击下载安装／更新或首次模型配置时查询官方稳定发布对应的二进制包。按实际平台匹配服务器与运行库，要求可信文件大小和 SHA-256；正常截图不联网检查更新，不自动升级显卡驱动，也不安装整套 CUDA／ROCm 开发工具。

官方元数据不可达时使用内置的 `b11146` 可信清单，并明确标为回退清单，不宣称已确认最新版。该清单的 Windows CUDA 候选为 12.4／13.4，Linux 为 12.8／13.4；不是简单按显卡新旧套用同一版本。安装包继续内置原有 `b10227` Vulkan／CPU，离线基础和轻量模式保留，专用 GPU 后端按需下载。

默认使用官方 GitHub。用户可主动开启第三方 HTTPS 备用源，或提供自定义 HTTPS 前缀；连接／读取超时可换源，并支持校验 Content-Range 的续传。所有来源均须通过官方或内置清单的大小和 SHA-256 校验，验证前不执行。第三方备用源不提供可信摘要，不接收截图、正文或凭据，其国内网络可达性不作全面保证。

运行包在独立暂存目录中安全解压，拒绝目录穿越和危险链接。通过版本与设备枚举检查后原子更新版本指针，不覆盖已加载 DLL，并保留旧目录及前一元数据。此检查不等同于模型推理验收；首次模型配置仍执行固定 OCR／翻译样例验证。

## 减少重复处理并修复超时

- 模型 OCR／翻译改用独立推理 HTTP 客户端，不再受普通网络请求的 **30 秒总超时**提前中断。
- 主翻译和受支持的轻量离线回退拥有独立时间预算；用户主动取消不会触发回退。
- 翻译失败后，在同一截图会话和相同 OCR 设置下重试，可复用原文，不再重复识别。图片、OCR 设置变化或成功后重新处理仍执行识别；缓存只存在于内存。
- 健康的自动回退后端继续复用，避免每次截图反复启动已失败的后端。新下载后端使用支持的自动 GPU 层数参数，旧内置后端保留兼容启动参数。

这些改动减少过早失败和重复工作，延长等待本身不代表推理更快。基础模式仍为本机视觉大模型 OCR → 本机大模型翻译，不恢复已删除的视觉纠错，也不静默替换为轻量模式。

## 退出并释放资源

主窗口和托盘增加明确的 **退出并释放资源**。真正退出时封锁新任务、取消进行中的处理，并停止本应用创建的 llama.cpp／Python 后端及其子进程。Windows 使用私有 Job Object 加强清理；某项清理失败不应跳过后端关闭。

只清理本软件拥有的进程，不按名称批量结束用户独立运行的 Ollama、LM Studio、llama.cpp 或远程服务。不删除模型、后端缓存、配置或凭据，不重置显卡。**主窗口右上角 × 仍是隐藏到托盘，不等于退出。**

## 升级与安装包

完全版安装身份及模型／配置目录保持不变。升级前请先从托盘退出旧版，再运行新安装程序。旧完全版通常可覆盖升级；旧标准版仍是不同安装身份和数据目录，本次没有新增跨版本自动卸载或凭据迁移。安装前若提示必须重启，请先重启再运行安装包，本版不绕过系统待重启检查。

本次提供以下四个 x64 程序包及 `SHA256SUMS.txt`：

- `PingYi-Complete-0.8.0-win-x64-setup.exe`
- `PingYi-Complete-0.8.0-win-x64.zip`
- `PingYi-Complete-0.8.0-linux-x64.deb`
- `PingYi-Complete-0.8.0-linux-x64.tar.gz`

CUDA／ROCm 包和大模型权重不直接捆绑进这些安装包。已有配置保留；启用新的专用后端请打开“设置 → 本地模型”，检测硬件并按提示下载、选择执行设备、应用配置。

## English summary

v0.8.0 adds local GPU inventory, explicit single-GPU selection, hardware-aware CUDA 12/13 and ROCm/HIP runtime candidates, and retains Vulkan/CPU modes. Runtime downloads are user-initiated, checked against trusted sizes and SHA-256 hashes, staged in versioned directories, and can use explicitly enabled HTTPS relay failover. If official metadata is unavailable, the application clearly uses a built-in known-version catalogue rather than claiming it found the latest release.

Model inference no longer inherits the general HTTP client's 30-second timeout. Failed translation can retry from matching in-memory OCR results, with separate model and offline fallback budgets. Quit and release resources stops only application-owned backends; closing the main window still hides it to the tray. Existing model files and settings are retained.

Windows/Ubuntu automated checks and real official CPU-package installation/startup checks passed. Physical CUDA/ROCm inference, multi-GPU identity and execution, speed gains and GPU-memory reclamation have not been hardware-validated; no universal performance or network-availability guarantee is implied. The four Complete-edition packages include the existing Vulkan/CPU offline baseline, not all optional GPU runtimes or model weights.
