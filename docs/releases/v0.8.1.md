# 截屏释义 v0.8.1 — 默认 Vulkan，手动切换与卸载运行后端

## 默认使用 Vulkan

新安装默认选择 **通用显卡 · Vulkan（默认）**，复用内置后端，不会仅因首次配置模型而强制下载 CUDA／ROCm 或更新后端。模型权重仍须由用户明确点击下载。

升级到 schema 13 时，旧“自动后端＋自动设备”组合迁移为 Vulkan。已明确选择的 CUDA、ROCm、CPU、Vulkan 和具体执行设备保留；用户仍可主动选择“自动检测（可选）”。旧配置无法判断 Auto 是否曾被主动选择，需要保留 Auto 的用户可在升级后重新选择。模型、端点、快捷键、语言和凭据不重置。

## 手动安装并切换后端

在 **设置 → 本地模型 → 显卡与运行后端**，选择 ROCm、CUDA、Vulkan 或 CPU，点击 **安装并切换到所选后端**。尚未安装的后端按可信目录下载安装，已有后端直接复用。切换本身不重新下载模型权重；仅选择下拉选项不代表切换成功。

流程为：准备新后端 → 启动／设备检查 → 停用旧进程并启动新后端 → 已配置托管模型的固定 OCR／翻译验证 → 保存配置。准备失败时旧进程不受影响；激活、验证、保存失败或取消时，保留原配置与文件，并尝试恢复原后端。恢复失败会明确提示，不假报成功。

未配置托管模型时，只保存通过启动／设备检查的后端偏好，仍需继续完成模型配置。外部 Ollama／LM Studio 等服务的后端需在该服务中设置，本软件不会擅自替换或停止外部进程。整页保存不能绕过显卡／后端切换验证。

## 卸载已下载的旧后端

切换成功后可选择旧后端，点击 **卸载所选已下载后端**，阅读提示并在十秒内再次点击确认。删除范围仅限本软件下载的该后端版本、元数据，以及能确认未被其他后端共享的下载缓存。当前保存或正在运行的后端不能卸载，须先切换到其他后端。

**安装包内置的 Vulkan／CPU 是恢复组件，保留磁盘文件，不通过此按钮卸载。**从内置 Vulkan 切换到 ROCm 后，旧的模型后端进程停止；未执行的恢复文件不持有模型显存。通过下载器安装的 Vulkan 更新版本可以清理，之后仍可使用内置 Vulkan。模型、普通配置、密钥、系统驱动和用户独立服务不会删除。

安装／卸载共用锁，并拒绝越界路径、符号链接和目录联接。被其他程序占用的文件会报告“清理未完成”，不虚报已释放全部磁盘空间。

## 状态与恢复

“后端尚未安装”“已安装但无可用 GPU”“检测失败”等提示移到显卡列表附近，避免空列表只显示 Auto 却被误认为已经就绪。成功操作后的列表刷新失败与实际切换失败分开显示。保留 v0.8.0 的显卡选择、可选备用下载源、大小／SHA-256 验证、推理超时修复及退出清理。

## 验证与兼容边界

回归覆盖默认与配置迁移、切换顺序、准备／激活／持久化失败回滚、取消、卸载二次确认、忙碌互斥、活动子进程保护、路径和共享缓存边界，以及中英文界面。正式发布工作流执行 Windows／Ubuntu 构建测试、四成品打包和干净 Ubuntu DEB 安装检查，附 SHA256SUMS.txt。

物理 NVIDIA／AMD 上的 CUDA／ROCm 推理、多显卡执行和显存回收仍未完成实机验收；不将合成设备或 CPU 包检查当作 GPU 认证。此版本没有新增驱动／ROCm SDK 安装器，不保证 ROCm 对任何 AMD 显卡都可用，也不保证一定比 Vulkan 更快。新后端没有可用设备时应保留可工作的 Vulkan。

## 升级

先从托盘退出旧版，再运行新版安装程序；完全版安装身份、模型和配置目录继续沿用。Windows 待重启安装检查不绕过。提供 Windows x64 安装程序／ZIP 与 Linux x64 DEB／tar.gz 共四个程序包。

详细操作见 [运行后端切换说明](https://github.com/qingshihuan/pingyi/blob/v0.8.1/docs/RUNTIME_SWITCHING.md)。

## English

Vulkan is now the default. In Settings → Local models, use **Install and switch to selected backend** to prepare/probe a replacement, activate it and verify an already-configured model before saving. Failed activation or persistence retains the prior configuration and attempts recovery. Model weights are reused. Without a configured managed model, only the backend preference is saved.

After switching away, confirm **Uninstall selected downloaded backend** with a second click to remove owned downloaded versions and unshared cache. Active/saved backends are protected. Bundled Vulkan/CPU recovery files, models, settings, credentials, drivers and external services remain. No physical CUDA/ROCm performance or universal AMD compatibility certification is claimed; this release does not install system drivers or the ROCm SDK.
